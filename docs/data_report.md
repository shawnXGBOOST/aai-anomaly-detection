## Decisions this implies

- **Scored set:** 80 channels (MSL: 27, SMAP: 53). Excluded: `P-2`, `T-10`. Their labels are ambiguous or missing, so any score on them would be unverifiable.
- **Interval convention:** interval ends are treated as inclusive. 11 intervals end exactly at the last index and 0 go past it, which is consistent with inclusive ends.
- **Scaling:** 14 channels have constant train telemetry and need a variance floor. Test telemetry leaves the train range in 54 of 82 channels, so inputs must not be clipped to the train range.
- **Warm-up:** the earliest anomaly starts at index 290, so rolling features and adaptive baselines must be warmed up with the end of the train series.
- **Metrics:** the longest single interval covers 50% of its series, so point-level metrics are reported only next to event-level metrics.

## Limitations

- Labels come from the original benchmark release and cannot be verified here.
- The benchmark treats every train series as anomaly-free; the data cannot confirm it.
- Constant-telemetry and range statistics use column 0 only; flags are not analysed.
